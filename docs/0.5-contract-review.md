paths. No compatibility shim is retained.

templates, examples, and docs. Production consumers already use root components;
there are no factory/type/deep-path production imports to migrate. Website prose/skills were migrated in website PR #67. Its generated 0.4 API
snapshot still lists the old factory/types and must be regenerated against the
